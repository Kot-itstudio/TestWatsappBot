# WhatsApp Voice Bot (Node.js, ESM)

Бот на @vansnowi/baileys со звонками через нативную сигнализацию Baileys (бесплатно, без Wavoip-токена), подменой микрофона и меню в стиле Godot. Без БД — только JSON-файлы.

## Требования

- Node.js 18+
- Системный ffmpeg (для mp3 -> PCM s16le 48kHz mono и Opus OGG для PTT)

## Установка

```bash
npm install && npm start
```

## Конфигурация

Настройки в `config.json`:

- `owner` — JID владельца для dev-команд
- `prefix` — префикс команд (по умолчанию `!`)
- `easter_egg_file` — файл-пасхалка в папке `audio/`
- `web_port` — порт веб-панели
- `voip.auto_reject_incoming` — автоотклонение входящих звонков
- `voip.sample_rate`, `voip.channels`, `voip.bitrate_kbps` — параметры звука

Звонки работают бесплатно через прямую сигнализацию Baileys (call-offfer / props / terminate) — сторонние сервисы и токены не нужны. Для исходящих вызовов поднимается вторая сессия (`data/auth-call`, сканируется отдельным QR или pairing-кодом), так как веб-сессии WhatsApp не поддерживают исходящие звонки. Если ffmpeg недоступен, бот логирует warn и продолжает работать без звонков.

## Запуск

```bash
npm start
```

QR появляется в терминале и на веб-панели http://localhost:3000. При обрыве соединения бот автопереподключается (кроме случая loggedOut).

## Команды (префикс `!`, русские и английские алиасы)

| Русская | Английская | Действие |
|---|---|---|
| !меню | !menu | вертикальное меню с маркером `>` |
| !меню вверх / !меню вниз | !menu up / !menu down | навигация с зацикливанием |
| !меню \<номер\> | !menu \<n\> | выбрать пункт |
| !выбор | !accept | выполнить выбранный пункт |
| !плей \<файл\> | !play \<file\> | играть mp3 из audio/ (без аргумента — первый файл) |
| !стоп | !stop | остановить плеер |
| !луп | !loop | повтор трека |
| !майд | !mute | мут микрофона |
| !микр | !unmute | снять мут |
| !звони \<номер\> [файл.mp3] | !call \<number\> [file.mp3] | позвонить по номеру и играть аудио в звонок |
| !выйти | !hangup | завершить звонок |
| !файлы | !files | список аудиофайлов |
| !статус | !status | состояние бота и VoIP |
| !помощь / !справочник | !help | справка |
| !разраб | !dev | меню разработчика (только owner) |

Во время активного звонка PCM-поток плеера идёт в медиа-мост; вне звонка трек дублируется PTT-голосовым в чат. При `!плей secret_message.mp3` срабатывает пасхалка.

## Dev-меню (!разраб / !dev)

Только для `owner` из config.json (остальным — «Команда не найдена»):
очистить_состояние, широковещ \<текст\>, перезагрузка, конфиг, тест_звук, звонки, справочник.

Рассылка `!широковещ` использует чаты из `data/chats.json` (автозапоминание при каждом входящем сообщении).

## Структура

```
bot.js            — ядро: Baileys, команды, веб-панель, вторая сессия звонков
calls.js          — CallManager: сигнализация звонков, ffmpeg-плеер Opus OGG
voip.js           — резолв и whitelist аудио из папки audio/
menu.js           — MenuState (up/down/pick с закручиванием)
menu.gd           — эталон меню на Godot
config.json       — настройки
views/index.html  — веб-панель с QR и статусом
audio/            — mp3-файлы для подмены микрофона
data/             — auth-сессии и chats.json (создаётся автоматически)
```

## Безопасность

- Резолв аудио: `path.basename()` + whitelist расширений (`.mp3 .ogg .wav .m4a`), защита от path traversal
- Спавн ffmpeg обёрнут в try/catch с понятными warn'ами — бот не падает
- Битый JSON (config/chats) не роняет процесс
